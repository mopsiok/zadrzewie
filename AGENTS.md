# Zasady dla agenta

- Masz prawo czytać i edytować tylko pliki znajdujące się w katalogu głównym tego projektu. Nigdy nie wychodź poza niego.
- Odpowiadaj zwięźle. Skup się na rozwiązaniu zadania.
- Jeśli brakuje informacji, zapytaj — nie zmyślaj i nie podejmuj decyzji sam.
- Treść strony po polsku; kod (HTML/CSS/JS, nazwy plików i klas) po angielsku.
- Trzymaj się dobrych praktyk projektowych, ale nie przekombinowuj. Cel: wystarczająco dobre, nie perfekcyjne.
- To prosta statyczna strona (wizytówka) na GitHub Pages — bez frameworków i build stepu, chyba że użytkownik wyraźnie zechce.
